## 📅 DAY 2 – OBJECT-ORIENTED PROGRAMMING

### Question 1 – Bank Account Management

**📝 Problem Statement:**

Create a class called `BankAccount` with the following:

**Instance Variables:**

- `accountHolder`
- `accountNumber`
- `balance`

**Requirements:**

1. A constructor to initialize all three variables.
2. A method `deposit(double amount)` to add money to the balance.
3. A method `withdraw(double amount)` to withdraw money if sufficient balance is available.
4. A method `displayDetails()` to display account information.

**In the main method:**

1. Create two `BankAccount` objects with different details.
2. Deposit money into both accounts.
3. Withdraw money from one account.
4. Display the updated details of both accounts.

**Concepts Covered:** Classes, objects, constructors, methods, and instance variables.

---

### Question 2 – Animal Kingdom: Inheritance

**📝 Problem Statement:**

Create a parent class called `Animal` with the following:

- `name`
- `age`
- `eat()` method
- `sleep()` method

Create two child classes: `Dog` and `Cat`.

**Requirements:**

1. Both child classes should inherit from `Animal`.
2. Add a `bark()` method to `Dog`.
3. Add a `meow()` method to `Cat`.
4. Create objects of both child classes.
5. Display their inherited and individual behaviours.

**Concepts Covered:** Inheritance, parent class, child class, and code reusability.

---

### Question 3 – Shape Area Calculator: Abstract Class

**📝 Problem Statement:**

Create an abstract class called `Shape` containing only one abstract method:

```java
abstract double calculateArea();
```

Create three child classes:

1. **Circle** – Calculate area using π × radius × radius.
2. **Rectangle** – Calculate area using length × width.
3. **Triangle** – Calculate area using ½ × base × height.

**Requirements:**

1. Each child class must implement `calculateArea()`.
2. Create objects of all three classes.
3. Use a `Shape` reference to call `calculateArea()` for each object.
4. Display the calculated areas.

**Concepts Covered:** Abstract class, abstract method, inheritance, and runtime polymorphism.

## 📅 DAY 3 & DAY 4 – PROJECT DEVELOPMENT

### 🚀 Project Title: Java Calculator Using Swing

**📝 Project Problem Statement:**

Develop a calculator application using Java Swing that allows users to perform basic mathematical calculations through a graphical user interface. The application should support addition, subtraction, multiplication, division, percentage calculation, and positive/negative number conversion. It should also provide a clear button to reset the calculation and handle division-by-zero errors.


### 📌 Project Description

The Java GUI Calculator is a simple desktop application developed using Java programming language and Swing. It provides an easy-to-use graphical interface with number buttons, mathematical operators, and a display screen.

Users can enter numbers by clicking the buttons and perform basic mathematical operations such as addition, subtraction, multiplication, and division. The calculator also supports percentage calculation, decimal values, and changing the sign of a number.

The application displays the result on the screen and provides an AC button to clear the current calculation. It also handles division-by-zero errors by displaying an appropriate message.

This project helped me understand Java Swing, event handling, and basic Object-Oriented Programming concepts.


### ✨ Key Features

1. User-Friendly Interface: Provides a simple graphical interface with number buttons and operators.

2. Basic Mathematical Operations: Supports addition, subtraction, multiplication, and division.

3. Percentage Calculation: Allows users to calculate percentages.

4. Positive and Negative Conversion: Allows users to change the sign of a number.
